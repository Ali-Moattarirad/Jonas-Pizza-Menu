# Jonas-Pizza-Menu

این اولین پروژه ای هست که جوناس توی آموزش هاش زده و یک منوی پیتزا فروشی هست.

توی این پروژه استفاده از کامپوننت ها رو یاد داده و نحوه به کار گیریشون رو کامل و دقیق توضیح داده.

نحوه عملکرد prop هارو توضیح داده و خیلی هم ازشون توی این پروژه استفاده کرده.

یک آرایه و یک لیست از دیتا رو مپ کرده و با کمک prop ها اونارو توی کامپوننت والد به نمایش درآورده ، خلاصه برای شروع پروژه باحالی بود و منم تصمیم گرفتم یکبار هم خودم بزنمش و اینجا اضافش کنم که بمونه :)
